@ delve

Your codebase is a dungeon. Folders are floors, files are rooms, functions are monsters, and the longest function in the repo is the boss.

Click the game, then arrows or hjkl to move. Walk into monsters to fight.

Post on X

The bestiary

  • Functions are monsters. Longer functions hit harder: a Rust function is a crab, Python a serpent, JavaScript a goblin, TypeScript a troll, Go a gopher, Java an ogre.
  • The longest function in the repository is the boss. Find its folder and slay it.
  • Comments are loot. A TODO is a healing potion, a FIXME maps the floor, an XXX is a bomb and a HACK is a sword that works, somehow.
  • Committers are ghosts that whisper their real commit messages.

Play your own code

The terminal version reads every file of a local repository, including private ones:

cargo install --git https://github.com/SAMARTHJAISWAL/delve delve-dungeon
cd your-project
delve

The browser version reads up to 160 files of a public GitHub repo. Your code never leaves your browser.
